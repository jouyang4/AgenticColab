# CLI reference

GENERATED by `tools/gen.py` from [`spec/cli.json`](../spec/cli.json). Read off `--help` and exercised live on `google-colab-cli 0.7.5`, with 0.6.0 kept alongside.

```bash
pip install 'google-colab-cli>=0.7.5'
# or: uv tool install google-colab-cli
colab version
```

## Facts

- `colab --version` does not exist; use `colab version`.
- Global flags precede the subcommand. `colab --auth=adc sessions` works; `colab sessions --auth=adc` -> `No such option: --auth`.
- `--auth` selects a credential MECHANISM, not an account. Identity comes from `CLOUDSDK_CONFIG`.
- No `colab whoami`. ADC files often carry an empty `account` field; identity is not readable after the fact.
- `exec` never takes code positionally, in any version. stdin or `-f`.
- `--timeout` bounds code execution only, not a lost websocket. Wrap every call in coreutils `timeout`.
- Builds share `sessions.json`; a session created by one build is usable by another.
- The binary installs to `~/.local/bin`, which is absent from a non-login shell PATH.

## Global flags

Before the subcommand, always.

| flag | meaning |
|---|---|
| `--auth <oauth2\|adc>` | credential strategy. oauth2 (default) = CLI's own installed-app flow + token.json; adc = Application Default Credentials. |
| `--config <path>` | session-state file. Default `~/.config/colab-cli/sessions.json`. |
| `-c, --client-oauth-config <path>` | client OAuth config JSON. |
| `--logtostderr` | CLI chatter to stderr; stdout stays pipeable. |

## Commands

### session lifecycle

| command | notes |
|---|---|
| `colab new` | allocate. Flags below. |
| `colab sessions` | list server-side assignments AND reconcile the local store: prunes local rows the calling account cannot see, refreshes proxy tokens. Bare only -- `colab sessions list` is an error. |
| `colab status -s NAME` | one session's state. `-s` takes the local label, never an endpoint id. |
| `colab stop -s NAME` | release. Resolves local labels only. |
| `colab restart-kernel -s NAME` | restart kernel, keep VM. |
| `colab url -s NAME [--open]` | browser URL attaching the Colab frontend to your existing VM. Pipeable. |
| `colab usage` | 0.7.x only. CU balance, burn rate, active assignment count. No side effects on the local store. |

### execution

| command | notes |
|---|---|
| `colab exec -s NAME` | run code in the session kernel. Code via stdin or -f only. |
| `colab repl -s NAME` | interactive REPL. |
| `colab console -s NAME` | raw TTY console. |
| `colab ssh` | 0.7.x only. SSH into the runtime, incl. an OpenSSH ProxyCommand bridge. |
| `colab run script.py` | allocate a fresh VM, run a local script, release. Works as a shebang interpreter. |

### files

| command | notes |
|---|---|
| `colab upload LOCAL REMOTE -s NAME` | one file. Large uploads fail intermittently -- chunk them. |
| `colab download REMOTE LOCAL -s NAME` | one file. |
| `colab ls [path] -s NAME` | default path `content`. |
| `colab rm PATH -s NAME` | remove a remote file. |
| `colab edit PATH -s NAME` | open a remote file in $EDITOR. |
| `colab install PKG... -s NAME` | pip install on the VM. `-r requirements.txt` works. |
| `colab drivemount [path] -s NAME` | mount Drive, default `/content/drive`. |

### meta

| command | notes |
|---|---|
| `colab log [-s NAME] [-n N] [-t TYPE] [-o OUT]` | session history. `--output` infers format from suffix: .ipynb, .md, .txt, .jsonl. Agent audit trail. |
| `colab auth` | 0.6.0: authenticate. |
| `colab skill` | print bundled SKILL.md (COLAB_SKILL.md on 0.6.0). |
| `colab readme` | print bundled README.md. |
| `colab update [--install]` | check PyPI; --install upgrades in place (Linux only). |
| `colab pay` | open the compute-units page. |
| `colab version` | version. |

### `colab new` flags

| flag | values |
|---|---|
| `-s, --session <name>` | local label; generated if omitted |
| `--gpu <T4\|L4\|G4\|A100\|H100>` | GPU shape |
| `--tpu <v5e1\|v6e1>` | TPU shape |
| `--high-mem` | high-RAM shape. Honoured for CPU/T4/A100; ignored for L4 and both TPUs (single shape each). 0.7.x only. |
| `(neither --gpu nor --tpu)` | CPU runtime |

### `colab exec` flags

| flag | notes |
|---|---|
| `-f, --file <path>` | execute a local file |
| `--timeout <float>` | code-execution timeout, default 30 s. Does not bound a lost websocket. |
| `--env KEY=VALUE` | 0.7.x only. Env var in the remote kernel. Repeatable. |
| `--output-image <path>` | save a plot |

### `colab run` flags

--gpu/--tpu/--high-mem, -s, --keep, --timeout, --env; script_args after the path arrive as sys.argv[1:]

### Requestable enums

| enum | values |
|---|---|
| `Accelerator` | `NONE`, `G4`, `T4`, `L4`, `A100`, `H100`, `V5E1`, `V6E1` |
| `Shape` | `STANDARD`, `HIGH_RAM` |
| `Variant` | `DEFAULT`, `GPU`, `TPU` |


What you get is an entitlement question -> [01](01-machine-shapes.md), [05](05-error-taxonomy.md).

## Internals

```python
from colab_cli.common import state, AuthProvider, SessionState
```

| object | notes |
|---|---|
| `state.client` | authorized client. Methods: assign, unassign(endpoint), list_assignments(), get_consumption_user_info(). Constructing it yourself from raw ADC credentials fails with `'Credentials' object has no attribute 'request'`. |
| `ListedAssignment` | endpoint, accelerator, variant, machine_shape, runtime_proxy_info (token, url, tokenExpiresInSeconds). list_assignments() mints a fresh proxy token per call. |
| `SessionState` | one row of sessions.json. Required: name, token, url, endpoint. Optional: token_expires_at, variant, accelerator, machine_shape, kernel_id, session_id, last_execution, running. |
| `state.store (StateStore)` | add, get, list, remove. |

**Enum trap.** accelerator/variant/machine_shape are ENUMS on an assignment and `str` on SessionState. pydantic v2 will not coerce them; a refused row makes the whole store fail closed. Write enum NAMES (`.name`), not values. -> [03](03-session-lifecycle.md#sessionsjson-fails-closed)

## Examples

**install and check**

```bash
pip install 'google-colab-cli>=0.7.5'
colab version
```

**account selection**

```bash
CLOUDSDK_CONFIG=~/.config/gcloud-A colab --auth=adc sessions   # account A
CLOUDSDK_CONFIG=~/.config/gcloud-B colab --auth=adc sessions   # account B
```

**exec: stdin or -f, never positional**

```bash
colab exec -s s1 'print(1+1)'          # Error: Got unexpected extra argument(s)
echo 'print(6*7)' | colab exec -s s1    # ok
colab exec -s s1 -f ./job.py           # ok
```

**colab run as a shebang interpreter**

```python
#!/usr/bin/env -S colab run --gpu T4
import torch
print(torch.cuda.get_device_name(0))
```

**two builds side by side**

```bash
uv venv --python 3.12 ~/colab-075
uv pip install --python ~/colab-075/bin/python 'google-colab-cli==0.7.5'
~/colab-075/bin/colab version   # leaves a shared `uv tool` install untouched
```

**enumerate assignments**

```python
from colab_cli.common import state, AuthProvider
state.auth_provider = AuthProvider.OAUTH2
for a in state.client.list_assignments():
    print(a.endpoint, a.accelerator, a.machine_shape, a.runtime_proxy_info.token[:12])
```
